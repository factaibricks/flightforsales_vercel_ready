IMAGES FOLDER — FlightForSales call landing page
=================================================

The page works perfectly with NO images (slots auto-hide). Add these to make it
look premium. Just drop the files in THIS folder using the EXACT names below.

1) logo.png   (or logo.svg — if you use .svg, change the filename in index.html)
   • Your FlightForSales logo.
   • Transparent background (PNG or SVG).
   • Height ~72px (displays at 36px, 2x for retina). Width auto.
   • If missing → the text logo "FlightForSales" shows automatically.

2) hero.jpg   (optional but recommended)
   • A friendly travel agent wearing a headset, OR a clean plane / travel shot.
   • Warm, trustworthy, real people convert best.
   • Size ~1200 x 500 px, landscape.
   • COMPRESS IT: keep under ~150 KB (JPG or WebP) so the page stays fast.
   • If missing → the hero image block auto-hides. No broken image ever shows.

Tips:
 • Free stock: unsplash.com / pexels.com (search "travel agent headset", "call center smile").
 • Compress at tinypng.com or squoosh.app before uploading.
 • Do NOT use airline logos or airline photos (compliance — independent agency).
